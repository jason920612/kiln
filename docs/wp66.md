# wp66:wp65 留下的缺口(鐵傀儡農場、完整突襲、隨機刻、觀察者漏掉、小輸出差異)

分支 `wp66-wp65-gaps`(從 main `8b57297f` 開出)。這一包的工作大多不需要真實客戶端(伺服器 console + 世界檔),所以先用 console 驅動器 `tools/wp58/p66rt.py`
(Kiln 在 VM `~/wp66`,port 25588;vanilla 26.3 在 `~/wp66/vanilla`,port 25594)並排跑,結果用 `tools/wp58/anvil.py` 直接讀兩邊的區域檔(**讀取完全不改方塊**)。

## 工具

| 檔案 | 做什麼 |
| --- | --- |
| `p66rt.py` | 兩個伺服器的共同 console 驅動:`run(cmds)` 把指令批次寫進 fifo、讀 log 到標記為止;`advance(n)`(`tick sprint`)、`step`、`gametime`、`day_time`、`counts`、`ready` |
| `anvil.py` | 最小的 Anvil 讀取器(26.x 把沒有屬性的方塊狀態寫成 `{"": "minecraft:air"}`,它也處理) |
| `rt_farm.py`、`rt_cactus.py` | 隨機刻取樣:耕地濕度每次被抽中減 1(7→0),所以 `7 - moisture` 就是這個方塊被抽中的次數 |
| `rt_cane.py` | 甘蔗欄位當計數器:`16 × (高度 - 1) + 頂端 age` 是這一欄被抽中的次數 |
| `rt_machine.py` | 觀察者+活塞甘蔗農場(wp65 的設計)N 組,跑 N 刻,數收到的甘蔗 |
| `rt_crops.py` | 小麥、海帶、樹苗的成長量 |
| `rt_golem*.py`、`tools/datapacks/wp66` | 鐵傀儡農場(含 tick 函數:記錄每隻新傀儡的時間與位置並移除) |
| `cmp_be.py`、`snbt.py` | 62 種方塊實體剛放下時的 `data get block`,兩邊逐欄比對 |
| `p66.py`、`p66_raid.py`、`build_agent_wp66.sh`、`vm_client66.sh` | 突襲真實遊玩(`ClientCtl` 新增 `bossbars`) |
| `wp66_start.sh`、`wp66_vanilla.sh` | 伺服器啟動(Kiln 的 `NOWORLD=1` 是處處超平坦;有世界目錄又沒有生成器的 Kiln 世界是**虛空**) |

(做這些的時候踩到的坑:`pkill -f` 的樣式出現在自己的 ssh 指令列上會殺掉自己的 shell;在 Windows 上用 python 改檔會把換行寫成 CRLF,在 VM 上 `sed -i 's/\r$//'`;
Kiln 的 `/fill`、`/setblock` 每個方塊約 1.5 ms(`with_level_held` 每次都重新建 `BlockEnv`),一次 4096 格的 fill 要 6 秒,vanilla 約 1 ms——沒有修,見「還沒做的」。)
